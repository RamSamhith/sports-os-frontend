# SportsOS

India's Sports Discovery Ecosystem.

## Status

Planning → Scaffold (this commit).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Shadcn UI
- Framer Motion

## Getting started

```bash
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` — local dev
- `pnpm build` — production build
- `pnpm start` — start production server
- `pnpm typecheck` — TypeScript check
- `pnpm lint` — ESLint
- `pnpm format` — Prettier
